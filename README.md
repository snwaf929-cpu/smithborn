# Smithborn website

The website for **Smithborn**, a Fabric mod for Minecraft 26.1.2 that gives vanilla gear random stats, quality tiers
and a Reforging Table, and for its six addons: Abilities, Legends, Metals, Enchantments, Arena and Trades.

The whole site is the single file `index.html`, served by GitHub Pages.
